## What human review covers

Human review covers a human check of a document the user built
in Studio, limited to:

- CV structure: section order, section presence, and whether the
  document reads clearly from top to bottom.
- Wording: clarity, consistency, and plain language in text the
  user already supplied, with suggestions the user can accept or
  reject.
- ATS readability: whether the document structure and wording are
  easy to read in plain text order, and which sections or keywords
  are missing from the text supplied, using the same heuristic
  limits as the ATS check in the app.
- Country pack fit: whether the template, paper size, section
  order, and photo choice fit the country pack the user chose,
  as formatting guidance only, not as a legal requirement.
- Letter review: a check of a letter generated in the letter
  studio, from fields the user supplied, including whether required
  fields are present and whether the letter still needs checking
  and signing by the sender before use.

## What human review does not cover

- No guaranteed job outcome, interview, visa, or any other outcome.
- No guaranteed ATS outcome. The ATS check is a heuristic check
  only, not a real ATS, not a score, and not a pass or fail result.
- No invented history. Human review must never add a qualification,
  employer, job title, date, certification, or achievement the user
  did not supply. Missing fields are prompts, not filled values.
- No legal or visa advice. Country pack fit is formatting guidance
  only. Questions about visas, work permits, or legal requirements
  are outside human review scope.
- No rewriting of facts the reviewer cannot verify. Suggestions
  must stay within text the user supplied, and the user must check
  every suggestion before use, just as with writer and letter
  output in the app.

## How it is requested

1. The user books the free 20 minute NVConsult consultation through
   the existing public route.
2. After the free call, the owner may personally invite the user to
   paid human review, and send the booking link privately. No paid
   human review link is published publicly in this increment.
3. The user supplies the document to be reviewed, and the reviewer
   checks only the scope listed above.
4. Suggestions are returned for the user to accept, change, or
   reject. A suggestion is never applied silently to the user's
   document.
